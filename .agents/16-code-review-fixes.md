# 14: Code Review Fixes

## 📝 Обзор

В ходе ревью были выявлены следующие проблемы:

1. **E2E Task Hang**: Проблема с зависанием Nx при запуске сквозных тестов через Playwright из-за некорректной обработки долгоживущих процессов (dev-серверов). Это произошло из-за изменений способа запуска dev-сервера (с прокидыванием порта из переменных окружения).

## 🛠 Реализованные решения

### 1. Стабилизация запуска E2E (Nx + Playwright)

Проблема заключалась в использовании `nx:run-commands` для запуска dev-сервера. Nx ожидал завершения процесса (exit), что для сервера никогда не происходит, блокируя запуск самих тестов.

**Решение**:

- **Разделение таргетов**:
  - `dev`: Оставлен как есть (`run-commands`) для ручной разработки, так как он поддерживает гибкую настройку портов через переменные окружения.
  - `dev-e2e`: Новый таргет, использующий специализированный исполнитель `@nx/next:server`.
- **Интеграция с Nx**: `@nx/next:server` корректно сообщает Nx о готовности сервера ("Ready in..."), что позволяет Nx сразу переходить к выполнению зависимых e2e-задач.
- **Playwright Config**: Обновлена команда `webServer`, чтобы она использовала именно `dev-e2e`.
- **Кеширование**: Выполнена очистка кеша через `nx reset` для корректного перестроения графа задач после изменения названий таргетов.

## 📈 Результат

- Команда `pnpm e2e` теперь работает стабильно и предсказуемо, автоматически поднимая необходимые сервисы и начиная тесты сразу после их готовности.
